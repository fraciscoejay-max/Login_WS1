# Login and role dashboards

The application supports student, teacher, admin, and super-admin accounts.
On first run, it creates these default management accounts:

- Super admin: `superadmin` / `superadmin123`
- Admin: `admin` / `admin123`

Sign in as the super admin and select **System Overview** to review account
counts, manage admin accounts, and open the teacher and student management
pages. Change the default passwords before deploying the application. The
super-admin account is intentionally omitted from the public registered-
accounts list shown on the login page.
